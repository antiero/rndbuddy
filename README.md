# rndbuddy

Native SwiftUI performance companion for the Cyma Forma RND synth, for iPhone,
iPad and Mac. Supports iOS 18+ and macOS 15+.

Open `rndbuddy/rndbuddy.xcodeproj` to work on the app. See the
[app README](rndbuddy/README.md) for features, setup and validation, and the
[contributor guide](rndbuddy/AGENTS.md) before making changes.

This is the standalone rndbuddy repository. It is an independent companion
project, not an official Cyma Forma product or a distribution of RND firmware.
